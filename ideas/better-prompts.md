I am a user of the application. When I branch off of a chat, focusing on a specific excerpt, sometimes I make decision in that branch that doesn't get propagated back to the parent chat. For example, I encountered an error in the code provided to me. I branch off of that work around to a fix on this branch. But then when it gets fixed and I go back to the parent chat, I then don't get the fix. The parent chat still assumes the wrong code it provide was correct. I hope there is a way to "back-propagate" the context? But it should be user controlled. I think user has to have the capability to choose whether they want the raw context provided (which is token heavy) or for the model to summarize what happened.
