# Contract: `branch_artifact` kind adoption across seams

**Feature**: `020-branch-backprop` | **Date**: 2026-09-06

The internal interface contract every touched seam must satisfy. Layering rule applies
throughout: only repositories issue SQL; components/stores call repos.

## 1. Types (shared surface)

```ts
// src/lib/chat/kinds.ts — EntryKind union gains:
type EntryKind = ... | 'branch_artifact';
// ALL_KINDS includes 'branch_artifact'; laneOf('branch_artifact') → 'internal'

// src/lib/db/schema.ts — drizzle kind enum gains 'branch_artifact';
// ord changes: integer('ord').notNull() → doublePrecision('ord').notNull()

// New metadata shape (near the chat kinds module):
interface BranchArtifactMetadata {
	mode: 'raw' | 'summary';
	sourceChatId: string;
	sourceChatTitle: string;
	branchPointMessageId: string | null;
	anchor: 'recorded' | 'derived';
	summaryTraceId: string | null;
	regeneratedAt: string | null;
}
```

Invariants: a `branch_artifact` row has `role === 'user'`, `parts === null`,
`toolCallId === null`, `toolName === null`. `search_vec` is never written
(generated column).

## 2. Repository seam (`src/lib/db/repositories/messages.ts`)

```ts

```

Guarantees: no function in this seam rewrites any other row. `append` continues to
allocate `max(ord) + 1` (integral). No rebalancing path exists.

## 3. Composition seam (read path)

- `src/lib/chat/context.ts`: `PROVIDER_EXCLUDED_KINDS` **unchanged** — `branch_artifact`
  is emitted with its stored `role: 'user'`. The `(depth, ord)` sort needs no change
  (`number` holds doubles).
- `src/lib/chat/projection.ts`: new mapping branch — `branch_artifact` row → one user
  message: framing header from metadata
  (`[Back-propagated from "<sourceChatTitle>" · raw|summary · <createdAt>]`) + blank line
  + `content`. Not added to `EXCLUDED_KINDS`. Participates in consecutive-user merge.

## 4. Search seam (`src/lib/db/repositories/search.ts`)

The raw-SQL kind filter extends from
`kind IN ('user_message','assistant_message')` to include `'branch_artifact'`.
No other search change; no index writes; no rebuild affordance.

## 5. Persistence/bootstrap seams

- Drizzle migration `0004_*.sql` (generated by `pnpm db:generate`):

  No `schema-migrations.ts` entry required (no data transform); restore of older dumps
  coerces integer values automatically. Never hand-edit generated SQL.
